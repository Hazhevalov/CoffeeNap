# Исправления по аудиту — 23 сентября 2026

## Выполнено

- Общая валидация формы, калькулятора и записи в SQLite: только конечные положительные значения, допустимые enum, кофе до 100 г, чай до 50 г, объём до 2000 мл, результат до 3000 мг. Это технические ограничения ввода, а не рекомендации по потреблению. Научная запись и переполнение больше не проходят через пользовательский ввод. Суммирование выполняется в double, включая старые большие значения.
- Исключение подписчика события после успешной транзакции больше не выдаётся за ошибку сохранения. Подписчики вызываются независимо с журналированием ошибок; это также применяется к удалению и сбросу.
- История загружается по 40 строк с курсором (ConsumedAt, Id), без пропусков одинаковых timestamps при добавлении/удалении. Дневной итог и распределение источников считаются по всей базе в SQLite, а не по загруженной странице. Добавление/удаление обновляет отображаемые показатели без полного перечитывания истории. Ошибки загрузки и удаления видимы пользователю; есть повтор загрузки.
- Обновление относительного времени затрагивает только видимые строки и публикует уведомление только при изменении текста. Таймеры останавливаются в фоне. На Android страница добавляется одним уведомлением диапазона; высота одинаковых строк измеряется по первой строке.
- Календарный кеш учитывает часовой пояс и смену даты, объединяет одновременные запросы одного диапазона. Месяц и неделя запрашиваются отдельно, без чтения промежуточных лет. Устаревший ответ не может перезаписать более поздний выбор месяца даже при задержке UI dispatcher.
- Миграция SQLite до версии 4 добавляет NameKey, сохраняя таблицы и записи. Известные старые русские/английские названия переводятся в ключи ресурсов; неизвестные названия остаются без изменения. История корректно переключает язык.
- Android backup и transfer rules исключают данные приложения; удалены ненужные сетевые разрешения. Политика конфиденциальности переведена и приведена в соответствие с настройками хранения. Ранее созданные системные резервные копии эти правила не удаляют.
- По уточнённому требованию сводные карточки и заголовок Your Consumptions закреплены: прокручивается только список записей внутри блока истории. Форма добавления также прокручивается. Исправлены локализация единиц/дневного лимита и активация вкладок после пересоздания Android Activity. Старые модели отписываются от событий при уничтожении окна; формы создаются заново для нового окна.
- Удалены дублирующие флаги видимости шагов, неиспользуемые обработчики/прогрев UI, повторная сортировка, дублирующее создание индекса и ненужные методы. Видимость ленивых шагов управляется одним механизмом.
